# Home walkthrough
Run: `cd walkthrough && python3 tools/serve.py 8000`, then open http://localhost:8000
Modes: Walk (click view, WASD, Shift run, Esc), Whole home, Room (pick from list; plan dimensions shown). In Room/Whole home click furniture to edit: G move, R rotate, Del delete, Shift+D duplicate, Ctrl+Z undo. Edits auto-save in the browser; Save layout exports JSON.
After changing the .blend: `tools/rebuild_walkthrough.sh`. Agent notes: CLAUDE.md
